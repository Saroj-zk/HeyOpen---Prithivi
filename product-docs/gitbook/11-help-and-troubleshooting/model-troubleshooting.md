# Model selection and response issues

If a model is missing, unavailable, slow, or returns an unexpected answer, start by identifying whether the issue is access, compatibility, or output quality.

## A model is not in my picker

Search by provider and model family. Check whether the catalog has changed, the model requires sign-in, or your plan does not include it. Models can be added, replaced, restricted, or retired.

## The model does not accept my file

Check supported input modalities, file size, and upload controls. A model that can generate images may not accept images as an input, and a large context window does not guarantee an equally large upload allowance.

## My response is incomplete

Ask the model to continue, narrow the prompt, or split a large document into smaller sections. Confirm whether the request exceeded available context or usage limits.

## I need up-to-date information

Choose a model with an active search capability, where available, and request reliable sources. Verify dates and citations. A non-search model can be stale.

## Different models disagree

This is normal. Review assumptions, check primary sources, and consider Compare for comparative analysis. Agreement is not proof.

## Slow or failed generation

Try a smaller request, review plan limits, or choose another suitable model. Do not repeatedly re-submit expensive requests without checking charges and processing status.
