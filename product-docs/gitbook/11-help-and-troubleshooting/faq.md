# Frequently asked questions

## Do I need an account to start?

The landing site advertises a guest-first chat experience. Some models, account features, and paid actions may require authentication.

## Is Hey Open one AI model?

No. It is a multi-model platform that connects users to different models and providers through one interface.

## How many models are available?

The public site advertises more than 200 models. Use the in-app catalog for current availability and account access.

## Can I choose a model myself?

Yes, choosing specific models is central to the product. The website also describes Auto routing for task-based selection.

## Does memory work across models?

Universal Memory is designed to make selected context available across supported models. The public page describes local browser storage and user-managed sharing settings.

## Does memory sync to another device?

The public memory page states that browser-local memory does not automatically sync across devices.

## Is every model zero retention?

No universal promise should be inferred. The Privacy Policy says zero-retention arrangements apply only to specific supported routes and activities.

## Is Pro always unlimited?

The marketing page uses broad unlimited messaging, while the Terms describe variable credits, eligibility, and usage restrictions. Confirm current entitlements at checkout.

## Can I pay with cryptocurrency?

The website advertises crypto payments where supported. Confirm the live network, asset, total amount, and renewal behavior at checkout.

## Is Consensus Mode always correct?

No. Multiple models can agree on a mistaken answer. Check important facts independently.

## Can I integrate Hey Open with my application?

The website shows an OpenAI-compatible chat completion example. Production access and the complete API specification must be confirmed for your account.

## Does Hey Open support x402?

The product discusses x402-ready agent access, but the public sources do not specify a complete live integration contract.

## Where can I ask for help?

Contact **support@heyopen.ai**. For enterprise inquiries, the public Enterprise page also lists **marketing@openledger.xyz**.
