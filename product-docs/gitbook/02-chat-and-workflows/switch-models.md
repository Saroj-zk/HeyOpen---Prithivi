# Switch models within your workflow

A central Hey Open workflow is choosing the right model at each stage of a project. You can begin with a quick model for brainstorming, then select a deeper reasoning model for analysis, and move to a creative model for media generation.

## Recommended workflow

1. Start a conversation with a clear task.
2. Open the model picker, if present.
3. Filter or search for a model by name, provider, capability, or modality.
4. Select the model and review any displayed cost, context, privacy, or sign-in requirements.
5. Continue the discussion and verify that relevant information is available to the newly selected model.

## Example: building a launch page

- Ask a general-purpose model for page structure and messaging.
- Switch to a coding model to implement the page.
- Switch to an image model for hero artwork.
- Return to a reasoning model for accessibility and conversion review.

The product guide illustrates this kind of multi-format continuation, but exact media sharing and file handling depend on the models and UI.

## What changes when you switch?

A different model may interpret your prompt differently, support fewer input types, or have a smaller context window. Its third-party provider and privacy route may also change. Universal Memory and chat context are complementary, not guarantees that every model sees or uses the same data.
