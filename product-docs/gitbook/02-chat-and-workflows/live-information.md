# Web search and current information

Some models listed on Hey Open advertise live-search capabilities, and the model interface depicts web-related badges on certain entries. Availability depends on the selected model and its current configuration.

## When to use a search-capable model

Search is useful for rapidly changing facts: recent announcements, software releases, schedules, market conditions, and newly published documentation. A model without browsing can answer from its existing training and context but may not know recent changes.

## Ask for sources

A useful prompt is:

> Find the latest official release notes for this library, identify breaking changes since version X, and include source links and publication dates.

Confirm that citations point to the source claimed. Verify dates, especially when comparing breaking news, historical summaries, or rapidly changing prices.

## Privacy considerations

Depending on the model and retrieval system, a search request may involve external services. Avoid placing credentials or confidential source text into search queries. Look for provider labels and review the processing route before using external search with protected information.

## If search is unavailable

Try a model specifically described as search-capable, provide the relevant source yourself, or narrow the task to material available in the thread. Do not treat an uncited claim about today's events as verified.
