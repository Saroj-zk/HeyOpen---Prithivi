# Account and wallet security

Protecting your account is a shared responsibility. Hey Open may use credentials, approved third-party authentication, wallet connections, API keys, or other methods depending on the feature.

## Basic security practices

1. Verify the official domain before signing in or connecting a wallet.
2. Use strong, unique credentials where password login exists.
3. Review unfamiliar device or activity alerts.
4. Secure your browser and operating system.
5. Revoke API keys that are no longer needed.
6. Review wallet signature requests before approving them.

## Never share these secrets

Passwords, one-time verification codes, API keys, private keys, recovery phrases, and wallet seed phrases should never be sent to an AI chat or support representative.

## If you suspect unauthorized access

Stop using the affected credential, review available sessions or wallet connections, change credentials through the official application, and contact **support@heyopen.ai**. If an API key was exposed, revoke or rotate it using the supported controls.

## Blockchain-specific cautions

Connecting a wallet may reveal its public address. Signing a transaction is separate from signing in, and on-chain transfers can be irreversible. Always inspect the requested permissions and destination.

## Data separation

Deleting local memory is not the same as revoking a wallet permission or API key. Each action uses its own control and may have separate consequences.
