# Example: create a campaign across modalities

This tutorial demonstrates how to plan a multi-model creative project. It is a workflow example, not a guarantee that every media tool is available in every plan.

## Goal

Create a 30-second product teaser from one concept, using suitable models for writing, visuals, motion, and narration.

### Phase 1. Define the message

Ask a text model to write a concise creative brief with the audience, desired takeaway, and visual direction. Request a 30-second script and scene breakdown.

### Phase 2. Develop frames

Choose an image model. Generate one reference frame per key scene using a consistent palette, subject description, camera direction, and aspect ratio. Keep the source files for later comparison.

### Phase 3. Introduce movement

Choose a video-capable model that accepts the relevant input type. Ask for motion based on each frame or text brief. Inspect the output for consistency and timing.

### Phase 4. Add audio

Draft a short narration and create audio if an eligible speech model is available. Generate music or a sound bed separately and check licenses before publishing.

### Phase 5. Review and finish

Use a reasoning or review model to check whether the creative sequence matches the original brief. Confirm facts, branding, duration, captions, and rights. Final assembly may require an external video editor.

## Keep track of source material

Store approved scripts, reference frames, audio, and decisions in your own project workspace. Browser-local chat history is not a reliable asset management system, and some generated media may be temporarily stored only.
