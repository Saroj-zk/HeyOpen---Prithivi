# Multimodal creation overview

HeyOpen promotes one workspace for text, code, images, video, audio, and music. The main benefit is the ability to choose different specialist models during a broader project rather than relying on one system for every output.

## Understand each modality

| Modality | Typical request | What to verify |
| --- | --- | --- |
| Text | Draft, summarize, analyze | Language and context capability |
| Code | Generate or debug software | Compatibility and test coverage |
| Image | Create or modify visuals | Input support, aspect ratio, restrictions |
| Video | Generate a clip or extend a concept | Duration, generation limits, delivery |
| Audio | Voice, transcription, sound | Language, audio format, consent |
| Music | Generate a soundtrack | Usage rights and provider conditions |

## A common workflow

Write a short concept with a text model. Turn it into a storyboard. Use an image model to explore frames, then a video model for motion and an audio-capable model for narration. The product guide presents this as a continuous project idea.

## What varies by model

Inputs, outputs, generation length, supported formats, latency, cost, temporary storage, and rights are model-specific. A model listed in the catalog may not be available to every account or support every kind of editing.

## Work safely

Obtain permission for media depicting identifiable people, review copyrights and licensing obligations, and check output quality before publication. Media processing can involve temporary storage under provider-specific arrangements.
