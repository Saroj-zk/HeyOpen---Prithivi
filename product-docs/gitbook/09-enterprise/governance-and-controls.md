# Enterprise workspaces and governance

Hey Open's homepage promotes capabilities intended to help IT and operations teams manage organization-wide AI adoption. Exact implementation and availability must be confirmed during enterprise onboarding.

## Control categories

| Control | Intended purpose |
| --- | --- |
| User administration | Add, remove, and manage employee access |
| Model access policy | Limit which AI models are available to a group |
| Usage and spending controls | Track or restrict consumption across teams |
| Audit visibility | Review relevant usage and administrative activity |
| Approved context sharing | Make selected organizational information available where permitted |
| Enterprise API access | Integrate internal tools with supported model routes |

## Suggested rollout

1. Identify who administers the workspace.
2. Establish permitted model and provider lists.
3. Classify information and choose approved processing routes.
4. Define spending limits, departmental attribution, and incident contacts.
5. Pilot low-risk workflows.
6. Validate audit, billing, and access-control behavior.
7. Expand gradually after a security and privacy review.

## Company memory

The marketing site discusses organizational memory, but the consumer Universal Memory page describes browser-local personal memory. Do not assume they have the same architecture, sharing model, or data residency properties. Request enterprise-specific documentation before enabling shared company context.

## Security and legal review

Ask for the exact scope of encryption, TEEs, external processors, retention arrangements, DPA, authentication integrations, certifications, and incident reporting terms.
