# Quickstart: your first AI conversation

This quickstart gets you from opening Hey Open to receiving and refining your first response.

## Step 1. Open Hey Open

Go to the [chat application](https://ais.openledger.xyz/chat). The website promotes a way to begin without an account, although some models and paid actions may still require authentication.

## Step 2. Choose how to start

If the interface presents a model picker, choose a model with capabilities that match your task. If Auto is available, select it to let Hey Open choose an appropriate model. Where a model displays a sign-in or payment requirement, follow the in-product prompt before continuing.

## Step 3. Send a clear request

A useful first request has a **task**, **context**, and **desired output**. For example:

> Create a five-day learning plan for Python. I know basic JavaScript, have one hour per day, and want a table with topics and exercises.

## Step 4. Review and refine

Read the answer carefully. Follow up in the same thread with changes such as: "Make day three more practical" or "Add a short quiz to each day." If an answer includes important facts, independently verify them.

## Step 5. Explore another model

Switch to another supported model to compare the approach. The active thread and locally saved preferences may help preserve continuity, but exact context-transfer behavior depends on the feature and configuration.

## Step 6. Check privacy and usage

Before uploading sensitive information, inspect the selected model's privacy label and review [How model routes handle your data](../06-privacy-and-security/model-provider-privacy.md). Paid or multi-model requests can use more credits than a simple chat.
