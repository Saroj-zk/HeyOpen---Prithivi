# Key product concepts

These terms appear throughout Hey Open documentation.

| Term | Meaning |
| --- | --- |
| Model | An AI system used to generate a response or piece of media |
| Provider | Organization or infrastructure service that supplies a model |
| Modalities | Input or output types such as text, image, video, audio, and music |
| Auto routing | Selecting a suitable model for a request rather than choosing it manually |
| Token | A unit used by many language models to measure input or generated text |
| Context window | The amount of information a model can process in one request |
| Universal Memory | User-managed context intended to work across supported models |
| Consensus Mode | A workflow that compares multiple model responses and may synthesize them |
| TEE | Trusted Execution Environment, an isolated computing environment available on certain routes |
| E2EE | End-to-end encryption, a distinct property that should only be claimed for routes that support it |
| Credits | Platform usage units that may be included in plans or purchased separately |
| API key | A secret credential authorizing developer API requests |
| x402 | A payment-related protocol discussed for agent and API interactions |
| $OPEN | The OpenLedger ecosystem token discussed on the token and staking pages |

For the full list and examples, see the [Glossary](../12-reference/glossary.md). Model names and provider availability change over time, so the in-app catalog takes priority over static examples.
