# What is HeyOpen?

HeyOpen is a privacy-focused, multi-model AI platform. Instead of choosing one AI provider for every task, you can access a broad catalog of models from one interface, use different models as your work changes, and keep relevant context through Universal Memory. The product is designed for everyday questions, serious research, software development, multimodal creation, and AI-powered applications.

The catalog is advertised as **200+ models across 32 providers**, with text, code, image, video, audio, and music capabilities. Actual model availability, usage limits, and provider arrangements can change. The model picker in the application is the source of truth for what is currently available to your account.

## What makes HeyOpen different?

- **Choice:** Select a particular model or use Auto routing when you prefer the platform to choose a suitable model.
- **Continuity:** Use Universal Memory to retain selected preferences and project context across supported models.
- **Multiple perspectives:** Compare can compare responses from more than one model.
- **Privacy controls:** Available privacy features depend on the selected processing route and model, including options promoted as encrypted or TEE-backed.
- **One workspace:** Move between conversation, reasoning, code, and supported media generation without managing a separate subscription for every provider.
- **Developer access:** A published OpenAI-compatible chat endpoint is shown on the website; production API access and available models depend on your account.

## What HeyOpen is not

HeyOpen is not a single proprietary AI model and does not necessarily operate every model it exposes. External providers may process requests. It is also not a substitute for professional medical, legal, financial, or other consequential advice. Model output should be reviewed before use.
