# Using documents alongside memory

The memory feature illustration includes a file area with an option to upload a PDF or text file and search its content alongside saved memories. The illustration displays a 10 MB per-file limit; production limits and available file types may differ.

## When this is useful

A project can involve facts you want remembered, plus reference materials that are too long or specific to store as short memory entries. For example, memory may hold the project name and style preferences while a document contains detailed product requirements.

## A practical workflow

1. Open the Memory area.
2. Check whether the file upload option is present in your account.
3. Upload a supported file that you are authorized to process.
4. Ask a model a question that depends on both your saved preferences and file content.
5. Verify the result against the document.
6. Remove the file or relevant local data when the project ends.

## Do not confuse the mechanisms

A saved memory entry is a compact durable fact. A reference file is source material that may be chunked and retrieved. Neither guarantees the model reads all of the original document for every question.

## Security and retention

A file may be processed for retrieval and, depending on feature and provider, temporarily handled or stored. Review the selected route's privacy information before including confidential information.
