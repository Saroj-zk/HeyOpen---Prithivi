# Add, review, edit, and delete memories

Universal Memory is most useful when its contents remain relevant. The public page describes a memory list that users can inspect, manually add to, and delete from.

## Add a memory

Open the Memory controls and choose the option for adding a saved fact if present. Write a short, factual entry with enough context to be reusable.

**Good:** "For the Atlas project, use British English and a technical audience."

**Less useful:** "I have something to do tomorrow." The second entry has no stable context or date.

## Review saved entries

Periodically check active projects, decisions, preferences, and constraints. Correct information that has changed. Automatic memory generation, if enabled, should still be reviewed for accuracy.

## Remove a memory

Use the delete or removal control next to the relevant entry. If the feature is browser-local, clearing site data may remove all saved entries for that site, but can also remove unrelated site settings and local sessions.

## Disable use versus disable collection

These are separate decisions. Turning off memory use stops the assistant from using saved context where the control is implemented. Turning off automatic memory generation prevents new facts from being saved automatically. Review whether existing entries remain stored after changing either control.

## Important limitation

Deleting local memory does not undo processing that already took place with a third-party model. It also may not remove operational billing or security records. See [Memory sharing and model providers](sharing-and-privacy.md).
