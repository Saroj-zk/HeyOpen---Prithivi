# Documentation changelog

## Version 1.0 | 5 November 2026

Initial GitBook documentation structure created from the publicly accessible Hey Open homepage, subpages, live chat shell, Privacy Policy, and Terms of Service.

### Coverage

- Getting started and user journeys.
- Conversation, model selection, and Auto routing.
- Multimodal generation and Universal Memory.
- Consensus Mode, privacy controls, and data handling.
- Subscriptions, payment methods, credits, and account management.
- API examples, integration guidance, enterprise solutions, and ecosystem concepts.
- Troubleshooting, FAQs, and support.

### Known limitations

Authenticated application screens, exact login flows, production billing rules, complete API schema, individual provider privacy matrices, and future token contracts were not publicly verifiable. Specific claims requiring approval are tracked in the non-published `EDITORIAL_REVIEW.md` file.

### Maintenance guidance

Update documentation when a model is added or removed, a new billing rule is finalized, an interface changes, API specifications are published, privacy arrangements change, or token features become active. Keep the date of each material revision visible to readers.
